# Настройка Telegram

vps-alert общается ровно с **одним чатом**. Он задаётся в `ALLOWED_CHAT_ID` в файле
`/etc/vps-alert/vps-alert.env`. Это может быть личный чат с вами или группа.

## Личный чат или группа

| | Личный чат | Группа |
|---|---|---|
| `ALLOWED_CHAT_ID` | Ваш ID пользователя, положительное число, например `123456789` | ID группы, отрицательное число, например `-1001234567890` |
| `ALLOWED_USER_IDS` | Необязательно: в чате только вы | **На практике обязательно**: без него сервером может управлять любой участник группы |
| Кто видит оповещения | Только вы | Все участники группы |
| Подходит для | Личного сервера | Команды, нескольких админов, нескольких серверов |

### Личный чат

1. Откройте своего бота в Telegram и нажмите **Start**. Пока вы этого не сделаете, бот не может вам
   писать.
2. Узнайте свой ID пользователя у [@userinfobot](https://t.me/userinfobot).
3. Укажите это число и как ID чата, и как разрешённый ID пользователя.

### Группа

1. Добавьте бота в группу и отправьте там `/start`.
2. Откройте в браузере `https://api.telegram.org/bot<TOKEN>/getUpdates` и найдите `"chat":{"id":-100...`.
   Сделайте это **до** запуска vps-alert: после запуска он сам забирает обновления, и эта страница
   будет пустой.
3. Перечислите в `ALLOWED_USER_IDS` через запятую ID всех, кому разрешено отдавать команды.

## Кто что может

- Команды принимаются только из `ALLOWED_CHAT_ID`, а если задан `ALLOWED_USER_IDS`, то только от этих
  пользователей.
- Все остальные игнорируются. Если бота добавят в чужую группу, он сразу из неё выйдет.
- О каждой отклонённой попытке приходит сообщение **⚠️ Попытка несанкционированного доступа**, не чаще
  раза в час на одного человека.
- Команды, отправленные, пока сервер был выключен, не выполняются, если им больше 5 минут. Например,
  «Бэкап сейчас», нажатый вчера, не запустится, когда сервер снова включится.

## Несколько серверов

Один токен бота одновременно может использовать только один сервер: Telegram отдаёт каждое
обновление одному получателю, а второй сервер получает ошибку
`Conflict: terminated by other getUpdates request`.

Поэтому создайте **по боту на каждый сервер** и добавьте их всех в одну группу. Тогда оповещения со
всех серверов будут в одном месте. Чтобы в группе с несколькими ботами обратиться к одному, добавьте
к команде его имя:

```
/status@shop_server_bot
```

На простой `/status` ответят все боты в группе.

## Переключение между личным чатом и группой

```sh
sudo nano /etc/vps-alert/vps-alert.env
#   ALLOWED_CHAT_ID=-1001234567890
#   ALLOWED_USER_IDS=123456789,987654321
sudo systemctl restart vps-alert
```

## Язык и справка

Бот говорит по-английски, по-узбекски и по-русски. Отправьте `/lang` и выберите язык или напишите
`/lang ru`. Сообщения, кнопки и меню команд Telegram переключаются сразу. Язык по умолчанию для новой
установки можно задать в env-файле: `LANGUAGE=ru` (или `en`, `uz`); `/lang` имеет приоритет.

`/help` показывает все команды с примерами, а `/help <команда>` (например, `/help schedule`) подробно
объясняет одну из них со ссылкой на эту документацию. Если команду, которой нужны аргументы,
отправить без них, бот покажет текущую настройку и примеры.

## Меню

Отправьте `/menu` (или `/start`): появится меню с кнопками для каждого раздела: состояние, процессы,
бэкапы, базы данных, сервисы, сайты, безопасность, оповещения и язык. Это одно сообщение, которое
меняется на месте при нажатии кнопок, поэтому чат не засоряется.

Частые значения тоже на кнопках: расписание (каждый день, раз в 3 дня, раз в неделю), готовые
варианты хранения, отключение оповещений на 30m / 2h / 1d, переключатели безопасности. Значения,
которые нужно ввести, например папку или адрес сайта, бот спросит, а вы ответите на его вопрос.
В личном чате просто отправьте ответ; в группе используйте **Ответить** (Reply) на вопрос бота,
чтобы он понял, какое сообщение является ответом.

Все команды продолжают работать, используйте то, что удобнее.

## Рекомендуемые настройки BotFather

- После добавления бота в свою группу выполните `/setjoingroups` → **Disable**, чтобы посторонние не
  могли добавить его в свои группы.
- Храните токен в секрете. Тот, у кого он есть, может писать от имени вашего бота и читать
  отправленные ему сообщения. Если токен утёк, выполните `/revoke` в BotFather и запишите новый токен в
  env-файл.
