# Heartbeat

Выключенный сервер не может сообщить, что он выключен. Если он остался без питания, завис или его
остановил хостинг, vps-alert останавливается вместе с ним, и в чате просто наступает тишина. А тишина
выглядит одинаково, когда всё хорошо и когда сервер мёртв.

Heartbeat переворачивает это: сервер регулярно сообщает внешнему сервису «я жив». Когда эти сигналы
прекращаются, вас предупреждает **внешний сервис**.

```
vps-alert ──(каждые 5 минут: «жив»)──► healthchecks.io
                                             │
                          10 минут без сигнала
                                             ▼
                                  📱 Telegram / email: «сервер не отвечает»
```

vps-alert каждые `HEARTBEAT_INTERVAL` (по умолчанию 5 минут) отправляет HTTP-запрос на `HEARTBEAT_URL`.
Сигнал отправляет сам сервис, поэтому так ловится и остановка или поломка сервиса vps-alert. О сервере
ничего не передаётся, только пустой запрос.

## Настройка с healthchecks.io (бесплатно)

1. Зарегистрируйтесь на [healthchecks.io](https://healthchecks.io). В бесплатном тарифе 20 проверок.
2. **Add Check**, затем установите **Period** 5 минут и **Grace** 5 минут.
3. Скопируйте URL проверки вида `https://hc-ping.com/xxxxxxxx-...`.
4. В разделе **Integrations** подключите **Telegram** (или email), чтобы получать уведомления.
5. На сервере:

   ```sh
   sudo nano /etc/vps-alert/vps-alert.env
   #   HEARTBEAT_URL=https://hc-ping.com/xxxxxxxx-...
   sudo systemctl restart vps-alert
   ```

Через несколько минут проверка станет зелёной (**up**).

## Uptime Kuma

Если вы используете [Uptime Kuma](https://github.com/louislam/uptime-kuma), создайте монитор типа
**Push** и укажите его URL в `HEARTBEAT_URL`. Uptime Kuma должен работать на **другом** сервере, а не
на том, за которым следит.

## Заметки

- Пока `HEARTBEAT_URL` пустой, heartbeat выключен.
- Если меняете `HEARTBEAT_INTERVAL`, задайте тот же период в сервисе мониторинга. Он должен быть не
  меньше `30s`.
- Намеренная остановка сервиса тоже вызовет оповещение «down». Перед плановыми работами поставьте
  проверку на **Pause**.
